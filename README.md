# Spider-Desk | Akıllı Arıza Talep Yönetimi

Mobil Programlama dersi Hafta 5 kapsamında React Native, Expo ve JavaScript kullanılarak geliştirilmiş bir arıza talep yönetimi uygulamasıdır.

## Özellikler
- Arıza talebi oluşturma ve form doğrulama
- Talep listeleme ve detay görüntüleme
- Uzun basarak talep silme
- Talep durumunu güncelleme
- Durum ve önceliğe göre filtreleme
- Anlık talep istatistikleri
- Spider-Man temalı arayüz

## Kullanılan Teknolojiler
- React Native
- Expo
- JavaScript (JSX)
- useState
- Pressable, FlatList, Modal
- Flexbox

## Kurulum

```bash
npm install
npx expo start
```

Expo Go uygulamasıyla QR kod okutularak çalıştırılabilir.

## Not
Veriler yerel state üzerinde tutulmaktadır. Uygulama yeniden başlatıldığında yeni eklenen kayıtlar korunmaz.
